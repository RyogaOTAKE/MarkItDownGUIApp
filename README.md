# MarkItDown GUI

## 対象
- .docx .pdf .pptx .xlsx を Markdown(.md) に変換します
- 単一ファイル変換 / フォルダ一括変換(サブフォルダ有無)に対応します
- 出力は入力ファイルと同じ場所に同名 .md を作ります

## 実行(開発)
1. py -3 -m venv .venv
2. .venv\Scripts\activate
3. pip install -r requirements.txt
4. python app.py

## exe作成
- build.bat を実行します
- dist\MarkItDownGUI.exe ができます
